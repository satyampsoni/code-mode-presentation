# Render free Grafana service

This directory is a self-contained Docker build context generated by:

```sh
node scripts/prepare-observability.mjs observability/render
```

Regenerate it whenever saved recordings, the dashboard or hosting templates change. Its recording JSON contains only aggregate measurements from complete paired runs. It contains no raw execution events, prompts, generated scripts or provider credentials.

The repository's `render.yaml` selects the free plan, Singapore region and this directory as the Docker context. Grafana is public with anonymous Viewer access; administrative login and signup are disabled. Prometheus and its metrics source listen only on loopback. Framing is restricted to the production presentation domain.

The free service sleeps after 15 idle minutes and may take about a minute to wake. Ephemeral data is reconstructed from the image on restart. This serves genuine recorded measurements, rather than collecting live agent runs. Free instance hours are shared with other services in the Render workspace. Keep the service on the free plan; do not enable paid resources for this demo.

Once deployed, set the Vercel production `GRAFANA_PUBLIC_URL` to the Render service's HTTPS URL and redeploy the presentation. Validate the health endpoint, dashboard, datasource and actual embedded panels before reporting completion.
